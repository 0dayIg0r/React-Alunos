# Aula 17 - Painel de Configurações

Projeto React para praticar:

- useState
- estados booleanos
- componentes
- props
- children
- onClick
- operador `!`
- operador ternário
- renderização com `&&`
- mudança de classe CSS com estado

## Executar

```bash
npm install
npm run dev
```

## Estrutura

```text
src/
├── components/
│   └── CardConfiguracao.jsx
├── App.jsx
├── App.css
├── index.css
└── main.jsx
```
