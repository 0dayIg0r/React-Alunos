# DevCursos - Projeto Base

Projeto React base para atividade de consolidação.

## Como executar

```bash
npm install
npm run dev
```

## Objetivo

Vocês devem desenvolver a aplicação utilizando apenas os conteúdos estudados até agora:

- componentes
- props
- children
- arrays e objetos
- destructuring
- spread
- map
- filter
- find
- import/export
- useState
- onClick
- renderização condicional
- formulários
- onSubmit
- preventDefault()

## Importante

O projeto não usa:

- API
- banco de dados
- localStorage
- React Router
- useEffect

Esses conteúdos ficam fora da atividade.
